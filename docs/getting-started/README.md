# Getting started

Read these in order. Together they take a bare Ubuntu server to a site serving
over HTTPS with key-only SSH access for its owner.

| | |
|---|---|
| [installation.md](installation.md) | Install the binary and run `ratline init` |
| [first-site.md](first-site.md) | Create a tenant and its first site |
| [adding-tls.md](adding-tls.md) | Get a certificate once DNS points here |
| [giving-access.md](giving-access.md) | Let someone else deploy to it |

Then: the [guides](../guides/) for your runtime, or `ratline explain` on the server
itself for the concepts behind any of it.
